# Mochi's Little Mission Countdown

A cute, responsive countdown companion for your deadline. Customize your mission, deadline, milestones, daily reminder time, and sound.

## Features
- Live countdown
- Custom mission and deadline
- Four editable milestones with progress
- Daily reminder while the page is open and awake
- 10 synthesized sound choices
- **Reminder sequence:** selected sound plays to completion, then browser speech announces the goal, time remaining, and a motivational quote
- Test Reminder and header sound-test button use the same sound-then-voice sequence
- Browser notification permission support
- Local browser storage

## Run
Extract the ZIP and open `index.html` in a modern browser. For the most consistent browser notifications and audio, serve it from a local or hosted web server.

## Reminder limitations
The daily reminder is checked while the page is running. Browsers and operating systems may suspend tabs, and this app cannot guarantee reminders while the page/browser is closed or the device is locked. Speech uses the browser's speech synthesis engine.


Voice selection: choose an English voice available on your device in the “Choose Mochi’s voice” dropdown. The app raises the speaking pitch and slows the rate to make it sound softer/cuter. Browser voice availability varies by device.
